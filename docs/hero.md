# Hero

De hero gebruikt `public/videos/hero-magnolia.mp4` als rustig, herhalend achtergrondbeeld.

Belangrijk:

- automatisch afspelen zonder geluid;
- beeldvullend op desktop en mobiel;
- statische projectfoto als alternatief bij `prefers-reduced-motion`;
- titel en CTA blijven als HTML-tekst toegankelijk en goed leesbaar.
